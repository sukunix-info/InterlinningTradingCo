## 📌 Project Overview

This repository contains the complete official website for **Interlining Trading Co.** (ITC Lion). The website is crafted with modern, responsive, high-performance web standards (HTML5, CSS3, Vanilla JavaScript) providing a dynamic and rich customer experience for wholesale buyers, boutique tailors, and garment factories.

### 🌟 Key Highlights & Features

- **Dynamic Interactive Catalog**: Browse 20+ specialized garment accessories and tailoring materials with category filters, instant keyword search, and detailed specifications.
- **Interactive Tailor & Fusing Guide**: Technical guidance on heat pressing, fusing temperature/pressure parameters, fabric compatibility, and care instructions.
- **WhatsApp Quote & Order Builder**: Real-time quantity calculator, order breakdown, and 1-click WhatsApp quote generator sent directly to ITC sales representatives.
- **Gujarati & Hindi Multilingual Support**: Accessible to local tailors and craftsmen with regional language cues and contact options.
- **One-Click Quick Actions**: Quick phone dialers, WhatsApp inquiries, shop directions on Google Maps, and copyable shop address details.
- **Fully Responsive & Fast**: Optimized mobile-first design, smooth transitions, glassmorphic accents, and lightweight asset loading without heavy external runtime dependencies.

## 🚀 Getting Started

### Local Development / Preview
Simply open `index.html` in any modern web browser or serve it via a local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node (npx)
npx serve .
```

Then visit `http://localhost:8000` in your browser.
